# Window Tagger

Chrome のウィンドウごとにタスク名の色ラベルを付けて、常に見える状態にする拡張機能です。

複数の案件を並行して進めていると、開いているウィンドウがどのタスクのものだったか分からなくなります。Chrome には標準で「ウィンドウに名前を付ける」機能がありますが、付けた名前はタスクバーにマウスを乗せるかメニューを開かないと確認できず、一目で分かりません。この拡張は、その名前を画面上に常時表示します。

## できること

- ウィンドウ単位でタスク名と色を設定し、そのウィンドウの全タブの右下にラベルを表示
- 色は 6 色から選択（色のほうが名前より速く識別できるため、色を主役にしています）
- ラベルの表示位置を四隅から選択（この設定は再起動後も保持されます）

## インストール

Chrome ウェブストアには公開していません。開発者モードで読み込んでください。

1. このリポジトリを clone または ZIP でダウンロードして展開します
2. `chrome://extensions` を開きます
3. 右上の「デベロッパーモード」をオンにします
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、`manifest.json` が直接入っているフォルダを選択します
5. ツールバーのパズルピースのアイコンから、Window Tagger をピン留めします

読み込んだフォルダは削除・移動しないでください。Chrome がその場所を参照し続けます。

## 使い方

タグを付けたいウィンドウで、ツールバーのアイコンをクリック（または `Ctrl+Shift+Y`）し、タスク名を入力して色を選び「適用」を押します。「解除」でタグを外します。

拡張を入れる前から開いていたタブには、ラベルを描く仕組みがまだ入っていません。一度再読み込み（F5）してください。以降に開くタブは自動で対応します。

## 注意事項

### タグは永続化されません

タグは `chrome.storage.session` に保存され、Chrome を終了すると消えます。Chrome のウィンドウ ID は再起動のたびに変わるため、永続化すると「前回とは別のウィンドウに以前のタグが付く」という壊れ方をします。毎回付け直す前提の設計です。

### ラベルが表示されない場所

以下のページでは、Chrome の仕様上コンテンツスクリプトを実行できないため、ラベルが表示されません。

- `chrome://` で始まるページ（設定、拡張機能、履歴など）
- 新しいタブページ
- Chrome ウェブストア
- PDF ビューア

これは拡張機能である限り回避できない制限です。

### 権限について

`<all_urls>`（すべてのサイトのデータの読み取りと変更）を要求します。すべてのタブにラベルを表示するために必要です。

この拡張は**ページの内容を読み取りません。** 行うのはラベル用の要素を 1 つ追加することだけです。ページのタイトルも変更しません。外部への通信は一切行わず、収集も送信もしません。依存パッケージもありません。コードは 4 ファイル・300 行ほどなので、動かす前に目を通していただけます。

## アイコンの差し替え

`icons/` の PNG を置き換えれば変わります。`manifest.json` の `icons` と `action.default_icon` が参照しています。

同梱のアイコンは `tools/make_icons.py` で生成しています。色や形を変えたい場合はこのスクリプトを編集して実行してください（Pillow が必要です）。

```
pip install pillow
python tools/make_icons.py
```

## 動作環境
