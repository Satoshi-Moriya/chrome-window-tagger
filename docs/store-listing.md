## ストアの掲載情報

### 拡張機能名（45文字以内）

```
Window Tagger - ウィンドウにタスク名のラベル
```

### 簡単な説明（132文字以内）

```
Chrome のウィンドウごとにタスク名と色のラベルを付けて常時表示します。複数の案件を並行して進めるときに、どのウィンドウが何の作業だったか一目で分かります。
```

### 詳しい説明

```
複数の案件を並行して進めていると、開いている Chrome のウィンドウがどのタスクのものだったか分からなくなります。

Chrome には標準で「ウィンドウに名前を付ける」機能がありますが、付けた名前はタスクバーにマウスを乗せるかメニューを開かないと確認できません。Window Tagger は、その名前を画面上に常時表示します。

■ 使い方
1. タグを付けたいウィンドウでツールバーのアイコンをクリック
2. タスク名を入力し、色を選んで「適用」

そのウィンドウの全タブの右下に、色付きのラベルが表示されます。

■ 特徴
・ウィンドウ単位でタスク名と色を設定
・6色から選択（色のほうが名前より速く識別できるため、色を主役にした設計です）
・外部への通信は一切ありません。情報の収集も送信も行いません

■ ご注意
・タグは Chrome を終了すると消えます。ウィンドウの識別子は再起動のたびに変わるため、保存すると別のウィンドウに以前のタグが付いてしまうためです
・chrome:// で始まるページ、新しいタブ、Chrome ウェブストアではラベルを表示できません（ブラウザの仕様による制限です）

■ ソースコード

```

## プライバシーへの取り組み

### 単一用途の説明（Single purpose）

```
Chrome のウィンドウごとに利用者が設定したタスク名と色のラベルを、そのウィンドウ内のタブに表示することです。複数のウィンドウを並行して使う際の識別を助けることのみを目的としています。
```

### 権限が必要な理由

**storage**

```
利用者が入力したタスク名と選択した色を、ウィンドウの識別子と対応付けて一時的に保持するために使用します。chrome.storage.session を使用しているため、Chrome の終了時に自動的に破棄され、外部への同期は行われません。
```

**tabs**

```
タグが設定されたウィンドウに属するタブを特定し、それらのタブにのみラベルの表示指示を送るために使用します。タブの URL や内容の取得、閲覧履歴の収集は行いません。
```

**scripting**

```
拡張機能のインストール前から開かれていたタブに対して、ラベル表示用のスクリプトを注入するために使用します。注入するのは本拡張機能に同梱された content.js のみで、外部から取得したコードは実行しません。
```

**ホスト権限（<all_urls>）**

```
利用者が開いているすべてのタブにラベルを表示する必要があるため、対象サイトを限定できません。この権限の範囲で行う操作は、ラベル表示用の要素をページに1つ追加することのみです。ページの内容の読み取り、タイトルの変更、フォーム入力値の取得、外部への送信は一切行いません。
```
